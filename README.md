# iOS Calculator (Ionic)

A fully functional, cross-platform mobile calculator application built using Ionic, featuring an authentic iOS UI/UX design. It captures the iconic look, smooth feel, and exact color palette of the native Apple iOS calculator while leveraging modern web technologies.

## Features

* **Authentic iOS UI/UX:** Faithful recreation of the Apple calculator interface, featuring the signature dark background, circular buttons, and distinct color hierarchy (dark charcoal, vibrant orange, and muted gray).
* **Cross-Platform Framework:** Built with Ionic, ensuring smooth performance whether run in a browser or deployed as a native mobile app.
* **Core Arithmetic Operations:** Accurate calculation engine handling addition, subtraction, multiplication, division, percentages, and sign toggling (+/-).
* **Responsive Grid:** Seamless button layout adapting across mobile screens and desktop viewports.

## Tech Stack

* **Ionic:** Framework for building the cross-platform hybrid mobile interface.
* **HTML5:** Semantic markup structure for the calculator layout and display screen.
* **CSS3:** Styling, custom variables, and flexbox/grid alignments mimicking iOS design guidelines.
* **JavaScript:** Core logic for handling state, user inputs, and calculation operations.
